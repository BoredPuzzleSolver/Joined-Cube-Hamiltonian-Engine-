# Terry's Model: SU(2) Joined-Cubes Recoupling

A Hamiltonian lattice gauge theory implementation for SU(2) on 3D joined cubic cell complexes.

## Features
- Exact local Gauss law resolution using Wigner 6j angular momentum recoupling symbols.
- Certified single-cube mass gap bounds: Δ_cube ∈ [2.941733, 2.958693] κ.
- Multi-cube chain spectra (N = 1, 2, 3) demonstrating exponential boundary shift saturation (Δ_∞ ≈ 2.8987 κ).
- Analysis of 3D bulk coordination with 6 neighbors.

## Requirements
- Python 3.9+
- NumPy
- SciPy
- SymPy
